1.  **Prioritize Popular UI/UX Skill Libraries**: For any UI/UX, frontend, or branding task, you **MUST** prioritize using and leveraging the knowledge from the most comprehensive skill libraries available.
2.  **Your Primary Source**: You **MUST** consider the **[UI/UX Pro Max Skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) as your primary knowledge base** for modern design standards. This includes its vast collection of 57 UI styles, 95 color palettes, 56 font pairings, and 98 UX guidelines[reference:2].
3.  **Self-Correction & Review**: Before outputting any UI code, you **MUST** review it against the design systems and best practices found in your available skills to ensure it aligns with professional standards.
4.  **Avoid Generic Outputs**: Do not produce basic or plain designs. Always strive to implement sophisticated, distinctive, and production-grade frontend interfaces as described in your `frontend-design` skill[reference:3].

## Automatic Skill Discovery & Installation
- **Step 1 - Contextual Suggestion**: When you identify a design task, first suggest a relevant design skill (e.g., `ui-ux-pro-max`, `frontend-design`, `canvas-design`, `threejs-*`).
- **Step 2 - Attempt Installation**: Propose to install the skill using its standard method or `npx` installer[reference:4]. You can say, *"To proceed, I need to install the `[skill-name]` skill. You can install it by running this command: `[install_command]`. Once confirmed, I can proceed."*
- **Step 3 - Proceed**: Only after receiving confirmation or detecting an existing installation, proceed with the task using the installed skill's expertise.
