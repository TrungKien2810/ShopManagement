# Quy uoc: docs/conflicts_resolutions

`docs/conflicts_resolutions/` dung de luu "bien ban giai quyet mau thuan" khi:
- Co 2+ phuong an thiet ke de bat dong (A/B/C), can chot.
- Co quy tac trong playbook/requirements mau thuan voi hien trang code.
- Co trade-off nghiep vu (tien/van hanh/UX/bao mat) can ghi ro tai sao chon.

Muc tieu: de nguoi moi vao doc la hieu "da chot gi, vi sao", tranh lap lai tranh luan.

## Template goi y
Tao file theo mau:
- `conflict_YYYYMMDD_<short_topic>.md`

Noi dung toi thieu:
- Boi canh (context) + link toi discussion/session/plan lien quan
- Van de (conflict) ro rang 1-2 dong
- Cac phuong an (A/B/C) + uu/nhuoc
- Quyet dinh cuoi cung (owner chot)
- Ly do + he qua (trade-offs)
- Viec can lam tiep (follow-ups)
