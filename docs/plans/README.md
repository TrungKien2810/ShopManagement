# Quy uoc: docs/plans

`docs/plans/` dung de luu "Ban ve thi cong" (implementation plan) truoc khi bat dau code.

Nen co cac muc toi thieu:
- Muc tieu + pham vi (in-scope / out-of-scope)
- Quyet dinh da chot (nguon su that)
- Hien trang & canh bao (noi de no ky thuat)
- Thiet ke Backend (API/DTO/validation/tenant/auth)
- Thiet ke Frontend (page/component/api client/UX rules)
- Phasing (P0/P1/P2) + acceptance criteria
- Test plan toi thieu

Ten file khuyen nghi:
- `story_<nn>_<ten>_plan.md` (neu gan voi story)
- hoac `implementation_plan_<chu_de>.md`

`docs/sessions/` la nhat ky phien lam viec. Neu session co noi dung ke hoach/phan bien, hay them link sang plan trong thu muc nay de tranh drift.
